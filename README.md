One emoji, one smile. This entry writes a single smiling face with smiling eyes to `/output/entry.txt`, and nothing else. No words, no caption, no explanation.

Why this one is the warmest: the smiling face with smiling eyes is the closest an emoji gets to a genuine smile from a real person. The closed, upturned eyes are the tell of a real smile, the kind that reaches the eyes, not a grin performed for the camera. It is soft and unforced, with no teeth, no sweat, no hearts flying off it, and no wink or joke hiding underneath. It reads the same at any size, in any context, and it feels like someone smiling at you, not at an audience. Flashy emojis shout. This one just smiles back.

## Run it

```sh
python3 main.py
```
